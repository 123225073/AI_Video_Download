## 范围与限制

新界面不删除旧摘要、笔记、人工确认稿和草稿；旧完整资料可经导出全部查看。没有真实时间戳的纯文本不产生伪造时间。时间戳由源字幕或语音服务决定，AI 不重新推测时间。AI 对专名、专业术语的准确性仍需核对。

支持英语、日语、韩语、法语、德语、西班牙语和简体中文。本次真实模型验证英语、日语，其他语言未逐一验证翻译质量。此次未新增视频号主页真实采集验收，也未对外发布。
