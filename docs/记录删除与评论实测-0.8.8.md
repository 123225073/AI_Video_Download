# 0.8.8：记录删除与评论采集实测

## 删除记录

任务中心和媒体库均可单条删除，也可勾选后批量删除。媒体库另有“选择失效记录”，便于清除已在本地移动或删除文件的记录。删除前会显示确认窗口，取消不会产生变更。

只删除当前页面选中的记录，不删除本地文件，不连带删除另一页面的独立记录、转录资料或二创稿。任务中心删除尚未完成的任务时，会先停止该任务，防止后台继续下载或把记录写回来；正在下载的对应媒体不能直接移除，先在任务中心停止或移除任务。删除记录后重启不会恢复。

## 为什么以前经常读不到评论

- B站网页已改用多层开放 Shadow DOM，旧的普通页面选择器读不到新版组件中的主评论和回复；作品网址自动补斜杠也会被旧检查误认为离开原作品。本版按同一作品标识判断，并读取新版组件。
- 小红书可能先弹登录框、后加载公开评论。以前看到登录框就停止，会丢掉本来可读取的首屏。本版先保存公开评论，再说明登录或设备登录超限限制；不把登录限制当成没有评论。
- YouTube 评论延迟加载，需要滚动到评论区；重复的网页节点 ID 不能作为评论 ID。本版改进滚动并使用评论永久链接标识。此外，下载器会话实际遇到“请登录，以便确认不是聊天机器人”，这属于平台登录要求，需要在官方窗口完成，程序会明确提示并保留已有资料。
- 视频号评论方法可能位于不同的官方模块，原来的定位和参数不完整；还可能把媒体库内部记录 ID 当成作品 ID。本版绑定实际评论方法、采用正确参数，缺作品标识时先从原作品确认。连接等待期间显示具体阶段，避免界面只写等待首批评论。
- 抖音目前在当前机器的 Chrome 和下载器内均出现连接关闭。这次证据不能归因为评论选择器，也没有证明平台可正常采集。

## 2026-10-16 真实检查结果

| 平台 | 下载器实际结果 | 验证边界 |
| --- | --- | --- |
| B站 | 实际读到首批 5 条评论 | 新版组件适配已实测；不代表所有分页和回复都完整 |
| 小红书 | 实际保留 5 条公开评论，随后提示设备登录超限 | 继续读取需要官方登录；没有绕过平台限制 |
| YouTube | 页面可加载，但下载器会话要求登录确认不是机器人 | Chrome 的另一会话可见 2 条，不能替代下载器验收 |
| 抖音 | 官网作品和首页均连接关闭；下载器同样未取到评论 | 当前网络下未通过真实采集验收 |
| 视频号 | 90 秒内没有等到微信采集页面接入，停止后恢复原连接 | 评论接口适配已通过隔离测试，尚未通过真实接口验收 |

因此，本版没有宣称“五个平台全部正常”。已确认的程序缺陷已修复；外部登录、微信页面接入和网络问题仍影响可用性。已有评论逐批保存，可停止后继续；没有明确末页证据时不会显示全部完成。

实测只读取公开页面和当前工具已配置的会话，没有发送私信、评论或其他对外消息。正式资料中的已有记录不因本次验收而自动删除。
