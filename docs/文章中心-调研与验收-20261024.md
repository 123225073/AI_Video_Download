## 开源项目调研

| 项目 | 可参考能力 | 本次取舍 |
| --- | --- | --- |
| [wechat-article-exporter](https://github.com/wechat-article/wechat-article-exporter) | 公众号文章与多格式导出；MIT | 项目宣布 2026-07-30 停止维护，原后台列表接口关闭，不作为整号同步后端 |
| [we-mp-rss](https://github.com/rachelos/we-mp-rss/blob/main/docs/weread-mp.md) | 订阅与增量采集 | 当前微信读书替代路径只返回最新一篇，不能回补历史 |
| [MediaCrawler](https://github.com/NanmiCoder/MediaCrawler) | 小红书搜索、详情及作者内容 | 当前 LICENSE 为非商业学习许可；未复制或集成其代码 |
| [XHS-Downloader](https://github.com/JoeanAmier/XHS-Downloader) | 图文／视频与元数据下载 | GPLv3；现有自有代码已有浏览器读取能力，无需嵌入整套下载器 |
| [RSSHub 微信合集路由](https://github.com/DIYgod/RSSHub/blob/master/lib/routes/wechat/msgalbum.ts) | 公开公众号合集 | 用于核对可访问的合集样本；实际实现读取页面公开列表 |
| [wechatDownload](https://github.com/qiye45/wechatDownload) | 公众号导出工具、合集与 Skill | 未确认可嵌入的完整核心源代码和许可，没有作为项目依赖 |

结论：公开单篇、公开合集和小红书图文可以在现有 Electron 架构中接入；公众号名称入口使用搜索索引，不能等同于完整历史文章抓取。

## 功能划分

| 入口 | 公众号 | 小红书 |
| --- | --- | --- |
| 链接采集 | 单篇／多篇公开文章 | 单篇／多篇图文笔记、短链接解析 |
| 作者批量 | 准确名称筛选索引，或公开合集／列表链接 | 博主主页的发布图文，过滤视频、收藏与点赞 |
| 关键词搜索 | 搜狗微信已收录文章 | 官方搜索页的图文结果 |
| 文章库 | 原文、作者、日期、图片、来源，四种本地格式 | 同左 |

独立的 ArticlePage、文章队列、SQLite、存储目录及浏览器连接。复用自有 ContentBrowser 的代码，不复用视频流程的运行实例。公众号读取不接入视频号代理／证书链路。文章数据库启动失败时，视频功能继续启动。

## 真实平台验收

证据：`output/articles-live-1792777044238/result.json`。

- 公众号关键词搜索取得 10 条结果，按“微信派”名称筛选取得 2 条，作者字段匹配。
- 公众号《春节发微信红包完全手册》取得正文及 19 个去重图片资源；离线 HTML 中 21 个图片位置全部实际解码显示（包含重复引用）。
- 小红书《星野智能体》取得正文及 1 张图片；离线 HTML 显示 1080×1800 图片。
- 小红书博主主页读取 3 条图文，关键词“读书”读取 3 条图文。
- 公开合集“李想主义”读取 3 条文章链接；页面展示 96 篇内容，本次没有声称已读取全部 96 篇。证据：`output/articles-20261024/album-probe.json`。
- 搜索临时跳转地址通过文章公开 biz/mid/idx 稳定去重。没有把临时签名 URL 当作永久文章身份。
- 修复真实验收发现的 GIF/WebP 解码兼容、微信表情图域名、图片锚点重复及搜索日期混入脚本文字的问题。

本次未完成整号历史全量采集测试；不承诺已删除、付费、私密或需要未完成验证的内容可采集。真实合集后续分页、过期短链接及长时间运行风控没有穷尽测试。
