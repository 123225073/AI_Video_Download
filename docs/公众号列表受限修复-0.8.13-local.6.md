# 公众号列表受限：分析、修复与验收

日期：2026-10-27。版本：0.8.13-local.6。

## 原因与证据

用户截图及本机文章资料库均显示：已识别“编程进阶录”，账号文章清单为 0，列表请求返回 200013。旧代码收到该值后等待 20/40 秒再次请求同一页，最多额外请求两次；最终只留下 failed 和错误文字，没有处理入口。原暂停状态仅保存在进程内，重启后丢失；重新点“更新获取”还会新建任务，从头开始。

当前接口路径和嵌套响应格式与维护者记录一致。请求是在微信公众平台所属的 Chromium 会话内发出，未发现把该请求交给另一套 Cookie/UA 传输的代码路径。现有证据不能把本次失败归为“少配了一个 IP”，也不能仅凭 200013 认定多久恢复、账号是否缺少能力、或是哪一条平台规则触发。

参考的一手实现记录：

- [当前账号列表流程与返回格式](https://github.com/Alex-giao/wechat-mp-article-list/blob/main/references/backend-workflow.md)：记录 appmsgpublish、publish_page/publish_info 及 200013/freq control。
- [wx-kit 开发维护记录](https://github.com/monkeychen/wx-kit/blob/main/docs/devlog/wx-kit-vibe-coding.md)：记录频控后的连续重试可能延长限制，以及暂停请求、保留队列的处理经验。这些实现记录不构成微信对本账号权限或恢复时间的承诺。

## 修复

1. 200013 立即结束当前请求，不再自动请求两次。HTTP 429 即使不返回 JSON 也按访问限制处理，保留登录会话。
2. 沿用一分钟的本机暂停间隔；服务器 Retry-After 更长时相应延长。暂停状态只保存返回代码和结束时间，跨重启保留，不保存登录令牌或响应原文。暂停结束后由用户手动继续。
3. 限制状态有独立弹窗和可重新打开的处理指引，说明本机暂停不代表微信承诺解除。提供保留任务、查看微信官方页面、切换已有文章链接采集的入口。
4. 同一受限作者任务再次点击“更新获取”时，复用原任务及分页位置。旧版 200013 失败记录能恢复成明确的受限状态，保留账号、输入、清单和游标。
5. 原文链接采集独立工作，不将原文冒充为账号历史列表获取成功。平台真实要求登录时仍使用原有微信官方扫码流程。

## 验证结果

- 修复前的两项回归稳定复现：重复请求三次、受限结果只有 failed；修复后相关单元检查共 21 项通过。
- 隔离官方域名响应的真实 Electron 界面验证通过：立即停止请求、明确弹窗、关闭后保留记录、切换链接不发送列表请求、重启不重发、手动继续使用原任务、非 JSON 429 保留登录。旧作者批量界面回归也通过。
- 对用户提供的真实公开文章执行独立验收：成功保存《在本地搭个 AI 网关，统一调度你的 AI 订阅》，作者“编程进阶录”，正文及 9/9 张图片完整保存。该验收使用独立资料目录，未导入用户登录，也未请求账号历史列表。
- 实际安装版使用原资料目录启动验证通过，显示受限指引；没有自动创建微信官方窗口或提交新的列表请求，前端无异常。原有 5 个账号、844 条受保护资料和 101 个素材保留，公众号任务核心信息及已有文章记录不变。
- 新完整安装包已在原目录实际安装成功，返回 0；2,651 个程序文件逐项 SHA256 一致，两个快捷方式及卸载程序正常。

## 安装兼容修复

本机文件保护会影响常规归档读取的文本字节，因此继续使用已授权读取的内容生成包。另通过小型及完整解包探针确认：现有 NSIS ZIP 解包组件不能正确处理 UTF-8 中文文件名，且不支持通过标准输入更新条目时产生的 ZIP64 局部头。普通 ZIP 工具能解码成功不等于该安装器能安装成功。

最终包使用已知大小的 ZIP32 条目；13 个中文程序文件在归档中使用 ASCII 临时名称，安装时由 Unicode NSIS 恢复原名。最终以实际完整安装成功和安装后全量文件核对作为交付依据。临时归档清理出现占用时不强制终止未知进程；收尾结果另存证据。

测试已改为显式绑定独立资料目录，避免打包程序忽略测试环境变量；首轮测试新建的默认空资料目录内样例记录已核实并移除，实际使用的原资料目录未混入样例。

## 尚未解决的外部限制

本次没有证明微信已解除对目标公众号历史列表的限制，也没有把单篇读取或模拟列表响应算成真实整号采集成功。没有换账号、切换 IP、修改代理/证书或绕过平台验证。真实账号列表是否可读，仍以微信官方允许的访问结果为准。

本机暂停结束后，通过真实安装版、现有会话继续了原任务一次。实际列表请求数为 **1**，微信仍返回 **200013**，结果保持 0 条；新版立即进入 `needs-action / wechat-rate-limit`，任务 ID 和账号身份保持一致，没有继续重复请求，也没有要求重新登录。证据：`output/repair-0813-6/live-account-result.json`。因此，此次能够确认程序已正确处理该拒绝，不能确认平台限制已解除。

最终清理完成：旧安装包、本轮失败包、打包中间文件及专用解包探针输出已按清单删除，实际释放 **15,810,726,470 字节，约 15.81 GB**。保留最新完整安装包、必要校验及说明、真实公开文章验证产物、用户数据备份和构建复现脚本。两个快捷方式及卸载程序保留。

证据：`output/repair-0813-6/`、`output/articles-restriction-e2e-1793031509933/`、`output/articles-public-live-1793031625410/`，以及相关测试日志。
