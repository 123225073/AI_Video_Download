# 0.3.3 抖音博主识别与批量下载验收

本机已更新至 0.3.3。抖音在真实官方页面通过了作者识别、作品读取和两条视频批量下载。视频号的真实微信读取仍未通过，等待用户完成 Windows 证书确认；不能以模拟接口测试替代真实验收。

## 修复范围

- 抖音短链接进入官方 iesdouyin.com 分享页时，转换为对应的桌面视频或主页地址；每一步跳转核对官方域名。跳回首页时明确要求重新复制链接，不识别首页推荐作者。
- 适配当前抖音视频页的作者区域。读取原视频作者 ID、昵称和头像；切换到错误博主时停止，并允许重新识别原链接恢复。
- 在工具自己的官方窗口读取原视频详情及作者发布列表的指定响应，补全封面、日期、时长及下载格式。每个条目核对原作者 ID；推荐、喜欢、其他作者响应不用于发布清单。
- 下载时重新获取所选视频的格式，由已有 yt-dlp 引擎下载并用 ffprobe 校验。下载格式仅保留在主进程及本次临时文件，结束后清理；不保存到界面清单。
- 图文、私密、付费、DRM 内容不作为普通视频下载。官方登录或验证仍需在官方窗口完成。
- 抖音界面不再显示微信连接准备提示。使用步骤保持“识别博主 → 读取作品 → 勾选 → 加入下载队列”，无需逐条播放。

参考了旧《风沙AI学习平台》的独立下载引擎及受控平台处理。旧项目的视频下载成功不能证明博主列表已支持；此次针对当前官方网页实现及验证。
