# 0.8.7 验收记录

本版修复视频转图文遇到事实差异后直接终止、继续按钮被禁用的问题，并将临时文本服务与响应格式异常接入有上限的自动恢复。没有放宽数字、事实或来源绑定校验。

## 已完成

- 全量自动测试 768 项通过；随后对一处格式恢复保护条件做小范围调整，受影响的 10 项稳定性测试再次通过。
- 隔离回放实际保存的八页失败候选：仅第 3、6 页进入修正，其余六页正文逐页一致；核验通过后保存为独立图文成稿，没有修改基准稿。
- 同一操作连续注入正文输出超时、复核超时、复核坏 JSON，系统补齐余页并自动恢复至完成，没有点击人工重试。
- 修正多页途中超时，只继续尚未修完的页；取消恢复等待后没有发起后续请求；持续失败有尝试上限，错误稿不会进入保存检查点或图片请求。
- 来源入口、同视频复用、语音识别、提示词编辑及切换保护、图片中断重启后跳过成功图片、小窗口布局等 8 组 Electron 端到端检查通过。
- 原有图文设置、中文输出合同、流式预览、事实拒绝保留原稿、播放器稳定和 SQLite 异常退出恢复等 6 组回归通过。
- 直接运行打包程序，旧事实失败候选的继续按钮可用；真实 IPC 提示词保存、重启恢复及批量生成确认界面通过。打包内 153 个 Electron、前端和 CLI 文件与工作区逐文件校验一致。
- 安装器退出码 0，原位升级成功。实际安装程序版本为 0.8.7，app.asar 与已验收打包程序一致。使用原用户数据目录启动，旧候选继续入口及生图提示词页签可用，界面没有脚本错误。
- 升级前已备份数据库；723 条受保护记录及 88 个素材文件在安装、启动检查前后逐项校验一致。桌面快捷方式保持原安装路径，重新启动后版本为 0.8.7，窗口可见，活动下载任务 0。
