## 使用流程

1. 选择素材，点击“开始转录”。仅生成识别原文，不自动调用文本模型。
2. 点击“AI 校正文案”，核对并编辑完整文案，点击“确认文案”。不需要先归档。
3. 多选目标语言，点击“生成所选译文”。摘要按需单独点击“生成摘要”。
4. 每种语言单独复制、导出；最后按需“确认归档”。

校正文案与摘要并排，多种译文并排；小窗口改为纵向。原始识别、时间戳与早期译文默认折叠。修改文案会阻止新翻译，需重新确认；旧译文保持可读，新版本生成成功后保存旧版本历史。
