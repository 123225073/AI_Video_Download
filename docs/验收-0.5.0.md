# 0.5.0 用户搜索交付验收

新增五个平台的关键词用户搜索、公共资料卡片、继续读取、官方验证窗口、选择用户进入原博主流程，以及共享后台的 CLI `search` 命令。没有增加第三方依赖。

## 验证证据

- 116 项自动测试通过。新增覆盖关键词/URL编码、稳定 ID、未知计数、同名用户、分页去重、账号切换、取消、风险冷却、旧结果保留、CLI参数和人工验证状态。
- 原生 Electron 隔离交互测试：五平台结果展示、1080×720 窗口、导航保留、验证中断保留结果、CLI共享服务、选定用户 ID 不被替换、没有自动下载；无前端异常。官方页面响应为测试样例，不作为真实平台验收。
- 原生 Electron 真实公开网络：YouTube 关键词 `AI` 返回20个频道；抖音未返回可识别用户卡片，需要人工验证；小红书官方页连接失败。视频号真实微信连接、真实 B站登录搜索尚未验证。
- 图文说明明确各平台条件、字段和真实验收范围。用户的微信参考短链接未能读取，不声称看过或完全复刻视频。

## 包与安装

- 0.5.0 正式程序：GUI/原生后台/包内 CLI 搜索登录前检查通过；真实 YouTube 搜索返回20个用户，其中7个提供头像地址。合成视频实际下载、CLI文件读取与探测、包内 NumPy/faster_whisper 导入通过。
- 安装包独立 7-Zip 完整性测试通过，包含2617个文件；app.asar、CLI入口/参数、截图和代表性 NumPy 文件与测试程序逐字节匹配。NSIS封装尾部提示是外层安装器附加数据。
- 首次归档读取一个 NumPy 测试文件失败，该包没有发布。最终构建生成安装器后清理中间归档遇到 EBUSY，构建进程退出1；独立完整性、文件比对和真实安装均通过，因此以独立验收证明安装器可用，不把构建日志写成全绿。
- 本机覆盖安装并通过原桌面快捷方式目标启动，版本0.5.0，五个平台选项可见，无前端异常。安装前备份并逐文件校验2295个资料文件；安装后首次启动前全部文件哈希不变，启动后40条业务/配置记录哈希不变。保留4个账号、5条任务、5条媒体。
- 升级时旧程序和登录窗口均未运行；旧库遗留的 B站“登录中”在启动时按已有恢复逻辑标为未登录，不声称已经登录或解除平台限制。搜索本身只保留本进程内公开结果。
