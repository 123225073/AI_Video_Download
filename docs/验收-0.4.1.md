# 0.4.1 B站封面与作者元数据修复

日期：2026-10-05。原案例：BV1MVbW6XEbZ，作者 UID 60542591。

## 原因与修改

1. yt-dlp 实际返回 `http://i2.hdslb.com/...jpg` 封面，Engine 只接受 https 导致空字段。现在安全升级 B站 CDN 地址，兼容候选封面与协议相对地址；图片错误后新地址可以重新加载。
2. 原作者列表使用 `--flat-playlist`，上游 BilibiliSpaceVideo 提取器只提供 URL 和 BV号。程序只在有日期筛选时补取详情，未筛选的列表因此缺少标题、图片和时长。
3. 改为 B站原生列表，保留 API 返回的标题、封面、时长、日期、原作者和实际总数；按实际 pn / ps 获取后续页，当前会话复用已经读取页。不同作者、无效分页和异常空页不会推进位置或假装到末页。
4. 352 / 412 / 401 列表限制现在明确分类，保存清单和位置，受限后冷却一分钟，不盲目循环。重新读取失败时保留原清单。
5. 新增“补全作品信息”和 `creator --record ID --refresh`，只补旧清单的缺失资料，最多50条，逐条保存；失败、停止和重试保留已补结果与原位置，不重新下载视频。
6. 单视频提取格式失败时，可用原链接公开详情补齐元数据；画质未知仍如实显示，下载能力以实际格式为准。分P、访问限制、队列与资料库规则保留。
