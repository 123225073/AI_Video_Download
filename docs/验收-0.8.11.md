## 本机测试限制

CLI 自动化脚本的冷启动成功，但嵌套子进程读取刚写的 JSON 清单时，被本机既有透明加密机制呈现为 `%TSD-Header` 字节，完整 CLI 下载脚本因此未通过。本次用独立最小样本确认了读写链异常，没有修改系统策略，也没有把它误报成产品逻辑测试通过。CLI 参数、资料路径与协议回归通过。

这台电脑的隔离资料测试不等于另一台干净 Windows 电脑实测。真实平台登录、验证码、付费接口、公司网络、不同版本微信插件均未在本版全面重新验收。
