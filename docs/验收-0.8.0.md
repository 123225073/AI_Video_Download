# 0.8.0：视频校对、原视频播放与视频转图文

## 本次修复与功能

- 普通、分段及带时间戳的校对传入流式回调，生成中的候选逐步显示；超时、停止、失败退出处理状态。本次校对计时独立于原视频下载和转录。
- 被数字、完整性或改动幅度校验拒绝的候选保留供对照，不替换原文或旧有效校对稿。支持明确等值的中文、阿拉伯数字及百分比转换，真实数值、顺序和编号前导零变化仍拒绝；有歧义的口述不猜测。
- 校对更新合并最新记录，保留并发取得的原视频文件。视频协议支持标准源、Content-Type、Range、206和416；字幕、音频地址不能冒充原视频。
- 原视频播放器保持稳定地址和节点；显式重试刷新本地失败缓存并保留播放位置，错误区分文件缺失、读取失败及解码失败。AI 文案完成不重置原视频。
- 视频工作台新增“视频转图文”。按口播组织正文、分页文案及配图方案，原文模式和当前稿模式分别选择标题和正文。自动画风读取最多4张有限代表画面，参考帧不作为成品且生成后清理；缺少视频或视觉能力时明确降级为仅口播。
- 手动画风可选择信息图、摄影、插画、漫画、杂志或自定义。页数可按内容规划或指定。自动配图默认关闭，只有显式开启才调用已配置的图片模型。
- 图文另存独立可编辑成稿，保留原视频和已有手工文案。通过事实核对的正文及每张完成图片及时检查点保存；取消、失败和重启保留已完成结果。同一任务不并发自动校对与图文创作。手工编辑后显示最新正文，初始分页单独保留。
