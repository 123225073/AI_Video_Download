# 0.8.10：博主作品直接转录与对标二创修复

博主列表中已读取的视频号作品，可以直接点击“语音识别”或“对标二创”。尚未下载过的作品按所选作品的原始 ID、作者及 nonce 取得视频，然后沿用原有转录、校对、二创流程；不需要先手动寻找分享链接或加入下载队列。

## 为什么关键词搜索能用，博主列表却提示“只有封面”

两种来源保存的资料不同：关键词搜索会保存已取得的媒体缓存，博主列表主要保存作品摘要和准确的获取标识。旧视频处理逻辑把“没有媒体缓存”直接判为“无法恢复的旧记录”；0.8.9 接入博主入口时，未补齐这两种来源之间的交接。此外，官方跳转链接中的 oid 是编码后的 ID，缓存使用原始十进制 ID，直接按跳转参数查询会再次误判。

即使只放开前面的提示，转录任务原来仍只接收链接和标题，后续无法还原所选作品。因此本次同时修复来源检查、任务保存、详情解析及下载交接，并精确核对返回的作品与作者，避免误用博主的第一条视频。

## 使用与边界

- 已有本地视频仍优先复用。已读取的博主条目保留完整获取标识时，可直接使用，包括升级前已保存的此类条目。
- 已下载媒体缓存按原始 ID 查询。没有缓存但来源明确时，仅为所选作品调用现有视频号详情获取流程；沿用现有连接期限和停止机制，取消后不会再开始下载。
- 没有准确作品身份、只有说明或封面的旧稿，仍需补充分享链接或本地视频，不把作品说明伪装成口播。
- 新任务将准确获取信息保存到转录来源，重启后可继续。此前已经建立但没有保存这些信息的旧转录任务，不批量改写，可从博主列表重新进入。
- 需要使用电脑微信取得尚未缓存的媒体时，仍要求官方视频号页面可连接；本版不宣称消除了微信插件自身的首次接入限制。
