# 0.3.4 视频号自动连接与确认弹窗修复

已安装到原程序目录，原有数据库、账号会话、任务和媒体完整保留。证书自动加入与移除、代理恢复、异常退出恢复均已在本机真实验证。微信作者列表与下载仍需取得微信页面连接后才能验收，不能用本机组件正常或模拟接口代替。

## 修复内容

- 视频号识别与下载自动准备内置组件，取消首次连接确认弹窗。
- Windows 专用证书通过 CryptoAPI 操作当前用户的对应证书记录，取消证书安装与移除弹窗；不改机器级证书库或全局保护策略。
- Windows 网络刷新与证书辅助代码预先编译后随程序内置，避开本机临时编译失败。
- 专用证书绑定本次连接的 SHA256 指纹。代理保留原上游与绕过名单；结束、取消、失败及异常退出恢复。
- 博主批量下载取消超过 30 条的重复确认，点击加入队列后直接分批提交。

## 使用

在“博主批量下载”粘贴链接并识别。程序自动准备微信连接；提示等待微信时，在电脑微信重新进入视频号页面并保持打开。取得连接后读取作品、勾选、加入队列，无需逐条播放。微信登录或验证码仍由微信处理。

上游也提供作者主页批量读取：[批量下载说明](https://ltaoo.github.io/wx_channels_download/feature/wxchannels/batch.html)。Windows 证书存储接口依据 [CertOpenStore 官方文档](https://learn.microsoft.com/en-us/windows/win32/api/wincrypt/nf-wincrypt-certopenstore)。
