# 0.3.0 对抗式审查与验证

审查方式：按用户流程和反例逐项检查源码，并运行破坏假设的负向测试与隔离桌面操作。此记录是本次自审与实际测试，不冒充独立第三方审计。

## 已定位并修正

| 反例/问题 | 修正与证据 |
| --- | --- |
| 新版 PyAV 改变接口，Whisper 打开音频失败 | 固定 PyAV 15.1.0；嵌入式 Python 的 base/small 实际中文转录通过 |
| 同一文件再次选择，因为导入ID变化绕过去重 | 以文件路径、大小、修改时间和处理选项生成稳定键；不同处理选项仍可另建任务 |
| 长摘要第二段失败，重试再次调用第一段 | 原文、摘要分段、译文分段检查点持久化；负向测试确认重试跳过已完成分段 |
| 审阅内容切页/重启丢失 | 独立审阅草稿自动保存；确认归档后才写入确认稿和归档索引 |
| 归档详情仍优先展示AI初稿，用户无法区分确认稿 | 默认展示确认摘要，独立AI初稿/原文/译文选项；所有正文按React转义，模型HTML不执行 |
| 服务返回200却未连接微信 | 检查官方 status.available；区分服务可达和微信在线 |
| 视频号数字ID超出JS精度 | JSON读取前保留长整数ID字符串，实测负向样例12345678901234567890无精度损失 |
| 微信作者列表返回55条，本页上限50条，后5条可能遗漏 | 保存页内缓冲及下一游标，续读后55条唯一条目保留 |
| 平台缺失游标或循环返回旧游标，误报完整/无限读取 | continueFlag和游标校验、历史游标检测；异常保留已读列表和前一游标 |
| 读取到半页后分享链接生成失败，游标提前前移 | 整页成功才提交检查点；失败半页不被当成读取完成 |
| 服务返回其他作者，或同名结果混入 | 原视频稳定ID核对；主页ID核对；拒绝推荐/收藏/其他作者；不按昵称搜索替代 |
| 浏览器被手动切到其他博主 | 读取前核对当前主页ID；错误页面不提交清单 |
| 更换模型服务域名时沿用旧密钥 | 密钥按服务域名绑定，切换域名需重新填写；禁止重定向转发密钥 |
| 密钥或服务错误正文暴露到网页/数据库 | 密钥仅Windows加密文件；快照/SQLite/任务无密钥；错误仅输出可操作的状态说明 |
| 静音交给AI后编造摘要 | 实际静音文件转录无语音，AI调用次数0 |
| 模型输出被截断却显示成功 | length/incomplete明确失败，保留原文，允许调整输出长度参数 |
| 用户取消后迟到回调覆盖状态 | AbortSignal校验与子进程停止；取消保留已有文稿，任务不被误标完成 |
