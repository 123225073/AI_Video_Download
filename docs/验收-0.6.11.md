# 0.6.11 视频号搜索接口与分页修复

## 问题与修复

微信页面的 WebSocket 连接正常，并不表示页面里的搜索接口已经被采集组件识别。旧实现依赖一次模块加载事件；微信复用缓存页面或接口较晚加载时，该事件可能已经错过。已连接的旧页面还会跳过连接准备，继续执行旧版适配脚本。

- 重新读取页面已公开的 API 组，并从页面实际加载的官方模块 URL 恢复模块单例；保留函数调用对象，不猜测模块版本、不执行下载的源代码文本。
- 模块恢复仅允许固定的微信官方域名及目标模块路径，并限制模块数量。
- 增加本地适配版本探测。旧页面连接不能再直接判定为可采集；接口缺失给出明确的适配错误，避免要求反复登录。
- 兼容实测的 `continueFlag` / `lastBuff` 与另一种 `objectContinueFlag` / `offset` 分页响应，保持同次搜索标识，拒绝缺失或重复游标。
