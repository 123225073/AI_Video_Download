# 0.3.1 视频号博主作品与自动连接

## 原因与修改

旧版能够通过元宝取得单个分享视频的作者昵称，但本机采集服务只运行 API 模式，微信桥接未连接，因此不能取得作者稳定 ID 和发布作品列表。旧列表的下载仍走元宝解析，存在作品列表与直接微信下载两条路径脱节的问题。

本版内置官方 wx_channels_download v260907，程序管理组件启动与连接准备。博主识别、分页清单、作者头像、封面、发布时间及平台报告数量走微信连接；勾选作品通过稳定作品 ID 与 nonce 取得实时媒体参数，核对作者后下载。媒体地址和解密参数不保存到 SQLite。

入口分别为链接下载、博主批量下载、转录与摘要、知识归档；AI 模型设置和视频号连接独立。尚未取得可读作者时，不再展示不能点击的整套读取、勾选和下载操作。

## 对抗式检查

本次为代码自审与反例测试，没有将其宣称为独立第三方审查。

| 检查 | 结果与证据 |
| --- | --- |
| 同名作者、错误作品被混入 | 以稳定 ID 核对，不用昵称搜索替代；作品/作者不一致时阻止下载 |
| 大整数被 JavaScript 截断 | ID、nonce 和解密参数在 JSON 解析前保留为字符串，覆盖真实长度反例 |
| 原媒体参数被持久化 | 只保存作品标识、分享链接与可展示元数据；加密下载 E2E 检查 SQLite 不包含解密测试密钥 |
| 服务可达被误当微信在线 | 分别展示组件准备状态与微信连接状态；未连接等待并给出重新进入微信的指引 |
| 并发任务提前恢复代理 | 引用计数共用连接，最后一个任务恢复；慢速准备跨越旧任务恢复的竞态也有反例测试 |
| 取消、错误、连接超时 | 恢复处理；守护启动失败时禁止切换系统代理 |
| 根证书或代理未获确认 | 首次 native 确认列明当前用户证书、代理上游、解密范围与恢复规则；授权绑定证书指纹 |
| 程序崩溃 | 隐藏的独立 PowerShell 守护监控 PID 与启动时间；真实进程终止的只读恢复记录实测通过 |
| 用户中途自行换代理 | 恢复仅在当前地址仍是本工具代理时执行，保留用户新选择 |
| 误删已有证书 | 仅移除本次新增且精确匹配指纹与名称的证书；原本已存在的证书保留 |
| 自动恢复失败 | 保留原状态记录，阻止新的自动连接，提供恢复原网络入口 |
| 中文路径与 Windows PowerShell | 分发脚本 UTF-8 BOM；状态 JSON 按 UTF-8 读取，原子替换记录；修复 detached PowerShell 静默退出问题 |

## 尚未验证的边界

用户提出按功能自动切换，但尚未明确确认本次实际证书信任；目前未安装根证书或改变系统代理，也未用当前微信会话读取目标作者的真实列表或下载。组件准备测试结束后服务已关闭，实际使用时由内置管理器启动。

不能据隔离测试宣称所有平台真实可用、该作者全量作品已取得，或 Windows 系统代理/证书真实变更与恢复已验收。真实验收需先明确授权临时证书信任与当前微信会话，随后在任务等待连接时重新进入微信视频号页面。
