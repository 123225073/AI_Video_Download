# 文章中心可用性修复（0.8.13-local.2）

用户截图复现地址：https://mp.weixin.qq.com/s/vzR1oTiRweG_skxyDW9HcQ

## 根因与改动

1. 链接识别仅建占位记录，用户未选择时保存按钮不可用。增加“采集并保存文章”，识别结果默认选中，并增加每条“保存文章／重试保存”。
2. 单篇文章被作者入口当作列表读取，错误返回需要验证。现在从文章读取真实作者，再查询作者文章；小红书笔记尝试提取其作者主页。原文保留在清单中。公众号搜索索引未覆盖其他文章时明确提示，不能伪装成全量历史。
3. 切换页签仍显示之前清单。现在仅显示属于当前入口／平台的清单，阻止误认旧结果。
4. 作者结果增加身份核对，公众号从原文取得 biz 后逐篇核验，拒绝同名但不同身份的公众号。检查也覆盖已缓存文章。
5. 重复保存原来仅检查 JSON 文件，其他正文或图片丢失仍跳过。现在检查四种导出文件及图片，缺失时重新采集修复。
6. 重试读取时防止复用已被切换到其他地址的窗口；含明确 biz/mid 的来源核对实际文章身份。
