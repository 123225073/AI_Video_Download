# 搜索自动恢复与专用浏览器（0.8.12）

安装完整 Windows 安装包后，软件按需启动专用 Chrome 或 Edge，自动准备独立资料目录和本机连接，不需要填写浏览器 IP、端口或每次批准接入。下载、音视频处理、语音运行环境和两个离线模型随安装包提供。

## 本版处理的问题

- 修正抖音首次搜索的打开顺序：新标签从空白页进入官网后才读取页面。旧流程会先读取空白页，再误显示为 `LOAD_FAILED` 网络故障。
- 对短暂页面切换和连接中断做有界恢复；登录和验证码不会被重复刷新。已经读取的作品、筛选条件和读取位置保留。
- 搜索遇到登录、验证、连接故障时，显示对应处理提示。可以打开官方窗口、检测并继续，或者稍后处理并保留结果。只有确认官方页面可以继续时才恢复读取。
- 区分“暂时未完成读取”和“确实没有符合条件的作品”，避免失败时误显示为空结果。
- 自动识别 Windows 登记的浏览器自定义安装位置，减少换电脑后误报未安装。

## 使用方式

选择平台、填写关键词后点击“搜索作品”。可自动恢复的短暂问题由软件处理；需要本人登录或验证时，按弹窗进入官方窗口，完成后返回软件继续。关闭提示可以稍后再处理，不会清除已取得的作品。

专用浏览器与日常浏览器的登录资料分开保存，首次使用需要在官方页面登录一次。平台会话过期后仍需重新登录。切换浏览器不会复制日常浏览器凭据，也不删除原浏览器资料。

本机已按用户要求切换为专用浏览器。其他电脑全新安装默认采用专用模式；已有旧浏览器绑定的安装仍保留原选择，可在账号管理切换。

## 安装与资料

运行 `FengshaVideoDownloader-0.8.12-setup.exe`，安装完成后从桌面快捷方式打开。

新安装资料位于 `%LOCALAPPDATA%\FengshaVideoDownloader\用户数据`，默认下载位置为系统“视频”文件夹下的“风沙下载”。已有安装沿用原资料库和下载目录。升级不清除账号、稿件或媒体。

专用浏览器使用电脑已安装的 Chrome 或 Edge。如果两者都没有，需要安装其中一种官方浏览器；电脑微信及其账号登录仍由用户按需准备。软件不会自动关闭其他软件的代理、修改系统安全策略，或代替用户完成平台验证码。

安装包通过 GitHub v0.8.12 Release 交付。验证记录见 [0.8.12 验收](验收-0.8.12.md)；独立客户电脑、平台登录限制和发布者签名仍需分别验收，不能将本机通过等同于所有电脑无条件可用。
