# 统一设置

全局侧栏只保留一个“设置”入口。设置内部使用左侧分类、右侧内容的工作区，沿用转录与翻译页面的蓝白风格。

| 分类 | 内容 |
| --- | --- |
| 下载与存储 | 保存目录、下载并发、默认画质、失败重试、文件夹规则、去重、账号管理快捷入口 |
| AI 模型 | 文本 AI 服务、模型读取、连接测试、语音服务与本地语音环境 |
| 视频号连接 | 微信连接准备、组件检查、恢复原网络、高级连接选项 |
| 应用与组件 | 应用版本、开机启动、下载运行组件与环境检查 |

## 使用逻辑

- 下载页“修改设置”进入下载与存储；转录页“AI 模型设置”进入 AI 模型；博主页的视频号连接入口进入视频号连接。
- 设置内部切换分类保留尚未保存的输入；进入其他业务页面仍沿用现有显式保存规则。
- 内部切换从页首展示，分类导航与页面标题固定，长表单在右侧独立滚动。
- 返回全局“设置”时保留本次打开的分类；应用重启默认进入下载与存储。
- AI 和视频号页面首次打开后保持表单实例；视频号页面隐藏后停止状态轮询。
- 设置分类集中在 SettingsPage 的四项清单中，后续可以按同一结构增加新页面。
- 帮助入口、打开方式与使用说明文件均保持原样。

此次调整仅涉及导航和设置布局，不修改下载、转录、模型请求或微信证书/代理处理逻辑。
