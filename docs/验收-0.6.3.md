# 0.6.3 搜索后台采集与逐批显示

日期：2026-10-09。

## 原因与修复

旧版先完成官网滚动读取，再串行打开小红书笔记确认日期；界面等待整次调用结束才更新，新关键词期间还显示旧结果。采集窗口默认显示。

0.6.3 通过原有应用事件持续推送当前搜索记录。开始搜索立即切换关键词；列表和已确认日期的作品逐批出现，停止后保存已取得资料。小红书用一个复用的详情窗口，在列表读取同时确认真实发布日期；搜索不必等待完整正文，克隆时仍核对正文与素材。不会用作品 ID 或模糊日期猜测发布时间。

已登录时采集窗口留在后台，不弹出、不自动播放声音；页面需要官方登录／验证时自动显示，可手工点“显示官方窗口”。保持原平台登录会话、系统代理以及 HTTPS 导航检查。

## 验证证据

同一实际小红书账号、关键词“乒乓球”、2026-09-09 至 2026-10-09、上限 10 条：旧版一次读取约 21.3 秒结束才切换新结果，列表阶段约 14.4 秒；优化后一次复测约 5.6 秒出现首批，19.5 秒结束。平台每次返回的作品及网络响应会变化；这是观察值，不是固定速度承诺。默认上限仍为 50，数量、日期均可修改。

153 项单元回归通过。新回归验证搜索开始切换、结束前增量显示、取消持久化、列表与日期核验重叠、验证窗口保留。Electron 界面回归验证后台默认隐藏、需要验证自动显示、手工显示、旧关键词清除和停止后保留结果。HTTPS 跳转回归验证没有明文 HTTP 请求。原有二创、真实 WebP 转换、实际 FFmpeg 成片及关键帧流程通过隔离回归；没有向真实平台发布或发送私信。

## 使用

输入关键词后搜索即可；不用手工开关采集浏览器或关闭系统代理。等待过程中可以看当前关键词、已读取数量、日期未知数量及已确认作品。需要操作某篇时可先停止采集再克隆；登录或验证按自动显示的官方页面完成，然后继续读取。

图文完整步骤见 [作品二创与评论采集](作品二创与评论采集.md)。上一版搜索、令牌和图片修复记录见 [0.6.2 验收](验收-0.6.2.md)。

最终构建和覆盖安装退出码均为 0。安装包 CRC、7 项关键载荷、46 个包内 Electron 源文件与最终源码一致；正式安装 ASAR 与交付包一致，内置语音运行环境导入通过。

正式桌面 0.6.3 使用原小红书登录账号和原系统网络进行真实搜索：约 4.0 秒出现首批 3 条且搜索仍在运行，官网窗口均保持隐藏。停止后保留首批并可继续；真实续读结束读取 52 条，其中 34 条符合日期范围，日期未知 0 条，界面无脚本错误。不是模拟搜索，也没有关闭系统代理。
