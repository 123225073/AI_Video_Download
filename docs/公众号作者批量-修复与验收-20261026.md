# 公众号作者批量修复（0.8.13-local.4）

用户目标：输入任意文章链接，自动识别公众号身份；点击“更新获取”，在当前界面显示该账号的文章清单；正常过程后台运行，选择后才保存全文。

## 根因证据

旧实现 `ArticleReader.discover` 先从原文识别公众号名称，再递归进入搜狗 `type=2` 全文关键词搜索，并按结果作者名称精确过滤。用户示例的搜狗结果包含其他账号，过滤后没有新增文章；旧实现又把原文放进结果，造成“批量读取只有原文一篇”的误导。“打开采集窗口”显示的正是内部最后使用的搜狗页。

真实原文 `https://mp.weixin.qq.com/s/HeK2GlRBGJGFDMg73HjikA` 提供公众号“编程进阶录”、biz `MzkwNjQ0MTIzNA==`、原始ID `gh_eaa8f55f35c3`、头像及简介“专注科技领域干货知识分享”。直接访问官方 `profile_ext` 返回“请在微信客户端打开链接”；兼容微信 UA 后仍相同。搜狗账号搜索也未命中该账号，不能将搜索引擎当作账号历史列表。

## 实现

- 作者入口粘贴文章后防抖识别公开身份信息，不读取正文归档、不下载附件、不建文章库记录。
- “更新获取”使用本应用独立的微信公众平台会话，从账号文章列表接口按 biz/fakeid 获取封面、标题、日期与链接；关键词入口保留原有搜索能力。
- 默认隐藏网页窗口。无授权时清楚显示需要连接，不自动打开搜狗或登录窗口，不向批量清单注入原文。用户主动连接后由微信官方扫码，识别登录完成后收起窗口。会话过期仍可能需要重连；需要具备公众号平台登录权限。
- 登录凭证留在隔离浏览器会话，token 不写入文章记录、不返回渲染层。API 网络请求限定为微信官方账号搜索和文章列表接口。
- 保存时继续逐篇核对公众号名称及 biz，拒绝同名异号。分页使用服务器偏移；重复分页不推进位置；批次中途限流保留已取得的条目与位置；登录过期保留清单。
- 修复封面被通用 flex 规则撑宽的问题。视频模块业务代码、代理和证书配置未改动。
