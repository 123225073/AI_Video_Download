# 0.3.0 转录、摘要、归档与博主读取

## 用户要求与验收边界

参考 AI-Video-Transcriber 融入视频/播客转录、摘要、翻译与归档；可编辑 CPA/OpenAI 兼容地址、密钥、模型发现和选择；保持现有下载、账号、媒体资料。博主读取使用原链接确定作者，禁止以同名搜索代替。

用户流程：新建下载 → 内容选择/博主作品 → 任务中心 → 媒体库 → 转录与摘要 → 审阅编辑 → 确认归档 → 知识归档/导出。
也支持直接输入转录链接、导入本地音视频/文本/字幕，不要求先到下载页。

## 接入约定

- 文本模型：默认 CPA 地址 https://cpa.fengsha.online/v1，可替换；GET models、文本连接测试、手动输入模型、刷新失败保留配置。密钥主进程 Windows 加密保存，不进入快照、SQLite、日志或网页存储。
- 语音：本地 Faster-Whisper，或用户选择的 OpenAI 兼容语音服务；语音与文本服务分别配置，不凭模型名字宣称语音接口可用。
- 转录：优先使用源字幕，缺失时提取音频；长音频分段，原文时间戳保留，长文本分块摘要/翻译；无语音禁止生成虚构摘要。
- 任务：本机持久化，单任务语音处理避免挤占下载；取消、重试、摘要失败后只重试 AI、重启恢复。只有完整生成的文件能导出。
- 归档：用户审阅确认，保留原文与来源、模型和时间；编辑确认稿，归档检索、Markdown/TXT/SRT 导出；不自动删除任何素材。
- 视频号：原分享链接作者字段尽量保留；本机 wx_channels_download 官方 API 获取稳定作者 ID 和发布列表，不能仅凭昵称匹配。连接未准备好时显示缺失条件及批量链接入口；不自动安装根证书或改变系统代理。
- 博主列表：分页去重、游标检查、作者校验、停止/继续；已读数量、筛选数量、平台报告数量明确区分，未取得总数显示未知。

## 验收记录

本地功能已实现。36项单元测试、真实中文音频本地转录（base/small）、静音防虚构、桌面转录归档导出/重启、原下载回归、博主分页/停止/恢复均通过；详情见《0.3.0-对抗式审查》。文本模型集成使用隔离模拟服务，不将其记为真实CPA调用。
