# Article Center Implementation Plan

> Execution: inline, using writing-plans and executing-plans. Existing user authorization covers implementation; preserve the current local video repairs.

**Goal:** Add a separate article center with link, author/list and keyword acquisition for WeChat public articles and Xiaohongshu image notes.

**Architecture:** Separate SQLite database and archive folder under 用户数据/文章中心. Article-specific IPC, windows, queue and UI. Reuse ContentBrowser instances for XHS detail/search, never reuse the running video workflow's instances. Read public rendered pages without installing proxies or certificates.

**Tech Stack:** Existing Electron, React, sql.js, Node test runner, Playwright; no new dependency.

## Constraints and verified research (2026-10-24)

- User requires all three acquisition entrances and isolation from existing video features.
- Preserve all pre-existing changes, accounts, downloads and video task records.
- https://github.com/wechat-article/wechat-article-exporter : MIT, maintenance stopped 2026-07-30 after article-list endpoint closure. Do not integrate obsolete account sync.
- https://github.com/rachelos/we-mp-rss/blob/main/docs/weread-mp.md : current WeRead fallback retrieves only the latest article; does not backfill history.
- https://github.com/NanmiCoder/MediaCrawler/blob/main/LICENSE : non-commercial learning license. Do not copy or embed.
- https://github.com/JoeanAmier/XHS-Downloader : GPLv3. Reference capability only; use existing owned code.
- https://github.com/qiye45/wechatDownload : release tool and skill visible; embedding license/core source not established.
- Live probe: Sogou article search works on this machine; first selected old result leads to account migration, not article content. Evidence: output/articles-20261024/live-probe.json.
- WeChat author-name collection means exact-author filtering of indexed results, explicitly NOT full history. Official album/profile links read only exposed article links. Login/verification/deletion/migration are actionable failures, not empty successful archives.
