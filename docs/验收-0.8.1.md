# 0.8.1 校对依据与画风卡片验收

本次修正视频处理的来源顺序：口播原文保留识别结果，AI 校对稿独立保存，二创和视频转图文默认使用校对稿。没有完整校对稿、口播已更新、数值候选尚未采用时，不能直接从识别原文创作。以前从原文生成的二创稿保留，提示重新基于校对稿生成。

AI 校对不再把识别原文数字当作正确答案。数值变化会收齐完整候选并显示变化，可对照原视频编辑后“确认并保存校对稿”。原文、原始时间戳和历史稿保留。重新校对不得自动回退人工确认的数字。中文数量、常用度量单位和量词纳入变化检查；不将“一起”“二创”等非数量词误判为数量。

新增 8 种带真实生成示例的画风卡片：赛博朋克、日系动漫、写实摄影、黏土3D、简洁信息图、水彩手绘、复古漫画、国风水墨。另保留自动参考视频与自定义。示例保存在 `public/video-styles`，随安装包本地提供，选择画风不调用图片服务。自动生成正文配图默认关闭。提示词与筛选说明见 [画风说明](视频图文风格示例.md)。
