# 视频来源接入、图文续接与批量配图（0.8.6）

本版将链接解析结果、博主作品和本地媒体接入原有视频工作流，并为视频转图文增加断点续接、可编辑生图提示词及批量配图。下载、登录、微信连接、原文和校对机制沿用原有实现。

## 使用方式

1. **选择视频**：链接下载识别后的“内容选择”、博主作品列表都有“语音识别”和“对标二创”。媒体库保留“转录与翻译”，新增“对标二创”。关键词搜索入口继续可用。同一来源已有任务直接打开，本地文件存在时复用。
2. **继续中断图文**：在“视频转图文”页签点击“继续图文处理”。完整页保留，未完整页单独补写，之后重新校验整篇的数字、事实和内容。正文完整但复核超时，只重新复核。校验未通过的候选不会自动当成成稿。
3. **编辑生图提示词**：校验通过后，系统自动转换为详细提示词。打开新增的“生图提示词”页签，编辑整组统一画风及每页画面、构图、文字和限制，点击“保存生图提示词”。旧版已保存方案可点击“转换为生图提示词”。转换在本地完成，不额外调用文本模型。
4. **批量生成**：点击“批量生成配图”并核对数量后确认，使用设置中的图片模型。每张图片通过解码检查、写入文件后立即保存。服务失败或停止后点击“继续生成剩余 / 已修改配图”。成功且提示词不变的图片会跳过；修改单页提示词仅更新该页，修改统一画风则整组需要更新。
5. **导出**：完成后点击“打开图文成稿继续编辑与导出”，复用现有图文编辑和导出入口。

## 截图中的实际中断原因

读取当时保存的任务记录：前七页对象完整，第八页正文未完成；候选结构校验失败，数字和事实检查尚未开始。文本配置为 120 秒超时、3000 token 输出上限，实际保存的错误是“模型服务超时”。因此能确认请求在完成前超时，不能把这次错误说成已证明触发了 token 上限。

旧实现把多页正文和配图方案放在同一次文本请求中。服务超时或输出截断时只保留显示预览，且预览没有配图方案字段；再次创作会从头请求。0.8.6 保存可恢复候选和来源绑定，续接按页完成余下内容。对于旧版本候选，沿用已完整显示的正文，以当前设置补齐余页和缺失配图说明，再完整复核，不直接信任未经校验的旧预览。

## 保留与验证边界

- 原视频、原始转录、校对文案和原视频二创稿保留。图文输出仍是独立派生稿。
- 生图提示词保存时校验稿件 ID 和版本，拒绝过期提交；未保存的提示词在切换页签时保留，切换视频任务前须保存。
- 配图使用已配置服务，实际质量及耗时由模型决定。统一风格约束会传入每页请求，但不承诺模型输出像素级一致。
- 本版没有放宽数字或事实复核规则。若候选确有事实问题，需重新创作，不应通过“继续”绕过校验。
- 图文正文在其他编辑器中修改后，需要重新整理分页方案再生图，以免按旧分页生成。
- 本次自动验收使用隔离资料库、合成视频、离线文本响应与可解码图片，验证实际 React/Electron/IPC/SQLite 链路；没有调用真实付费图片接口，不把流程通过等同于真实模型效果验收。
