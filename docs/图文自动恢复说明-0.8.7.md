# 图文自动恢复（0.8.7）

用户点击创作后，正文生成、数字检查、事实复核、生图提示词转换连续执行。可恢复的文本异常在同一次操作内处理，不再遇到一次问题就要求用户重来。

- **事实差异**：将校验意见和本次基准稿交给修正步骤。意见明确指出页码时，只改这些页，其余页保留。每页修完保存断点，之后重新核验整篇，最多自动修正两轮。
- **超时、断流、输出截断或暂时限流**：最多自动恢复两次，等待后继续未完成的步骤。正文已完整时只重做复核；部分页完整时保留完整页，只补余页。
- **响应格式错误**：最多恢复两次。复核响应格式错误只重做复核，不重写正文；图文结构或页数不正确时重新取得合法方案。
- **旧的失败候选**：“继续图文处理”不再因事实检查失败而禁用。它会带上上次的问题意见进行自动修正，仍需重新通过检查。
- **停止与重启**：自动恢复期间仍可停止。正常重启后保留断点，用户再次继续时接着未完成的位置处理；启动程序本身不重新调用模型。

## 这次提示的原因

本次任务的八页正文已完整，数字检查已通过；事实复核指出第六页将“进也进不去”弱化成“并不会因为有了AI就能轻易进入”，第三页将“可能未来是最值钱”弱化成“可能成为未来很值钱”。这是内容复核拦截，与此前未输出完的超时不同。

0.8.6 只能继续未输出完的内容，没有在事实不通过后自动修正，界面还禁用了继续按钮。0.8.7 修复这两个环节，保留原有数字与事实检查。

## 必须明确的边界

自动恢复会增加有限的文本请求，按当前服务计费规则可能产生费用。密钥、权限、接口配置及明确余额问题仍需修复配置；持续故障或两轮后仍有事实差异时保留候选与此前成稿，显示可操作的原因，不无限调用，也不把错误内容当成成功结果。

图片生成仍按用户确认的批量操作执行。已完成图片逐张保存；图片请求失败不会进入文本恢复循环或自动重复收费，原有“继续生成剩余 / 已修改配图”入口继续可用。

验证使用隔离资料库及离线响应，包含本次真实失败候选的回放。流程通过不等于真实付费模型的每次响应都稳定，也不代表全部平台采集已重新验收。
