# 转录与翻译工作区设计

按用户指定的用途组织页面：分类管理素材、核对原文与矫正文案、保留格式翻译。采用 frontend-design Skill 的可读性、清晰层次和真实可用界面原则，沿用现有白底蓝色视觉，避免增加无关模块。

## 空间与操作顺序

```text
应用导航 │ 文案目录、子目录 │ 文案对照 / 多语言翻译
         │ 素材搜索与清单   │ 不带时间戳原文 │ 不带时间戳矫正文案
         │                 │ 带时间戳原文   │ 带时间戳矫正文案
```

转录只生成两份原文；AI 矫正是独立按钮，两种结果同时完成后显示。上下区分格式，左右区分版本，让同类内容直接对照。面板分别滚动，可同步滚动左右同类文案。头部显示素材名、目录、处理状态，正文拥有主要空间。

翻译作为单独工作视图：来源选择 → 纯文本或时间戳格式 → 多选语言 → AI 翻译。各语言按相同格式并排显示。较多语言横向滚动，避免挤成窄列。1080×720 窗口保持对照结构，缩小应用导航为图标并提供名称提示；文案区域不出现整页长滚动。

目录支持新建、子目录、重命名、按目录过滤、素材移动与全文搜索。结果随任务自动保存。新建素材时才展示链接与导入表单，处理页面不重复摆放大表单。去掉摘要、笔记、人工归档按钮和独立知识归档入口。

## 内容和边界

- 原文只由字幕或语音转录产生；纯文本导入没有真实时间戳时明确提示。
- 模型接收带稳定编号的文字段落。段数、编号顺序、非空和矫正完整性检查通过后，程序将原始起止时间放回结果。模型不能改写时间位置。
- 矫正不做总结或重写；专名仍可能需要人工核对。
- 翻译按来源、格式、语言独立保存。失败可继续，其他完成语言保留；未完成内容不会冒充完整译文。
- 每种文案支持复制、TXT；时间戳文案可导出 SRT，导出全部包含各格式和语言。
- 升级保留旧资料、配置、加密密钥与下载账号。旧摘要、笔记、人工稿和草稿不删除；旧完整资料可通过导出全部查看。
- 实际本地音频、模拟模型流程和安装版真实 CPA 模型分别验收，不混淆模型真实性。
