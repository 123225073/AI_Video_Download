2026-10-13，本地修复及安装验收。源码和当前安装程序位于本项目及原约定程序目录；本次未发布到 GitHub。

## 已修复

- Clash 规则比较识别中文域名的 IDNA 编码和国家代码大小写，不再误报临时规则冲突；仍拒绝不同规则、目标、顺序或禁用状态。
- 保留 REALITY short-id 等文本字段的原词法值，避免科学计数或前导零转换导致 HTTP 400；兼容 null、锚点和别名，不修改节点选择或订阅文件。
- 搜索不再截掉第1000条之后的匹配作品；日期补查避免一直重试失败前缀；YouTube 取消前200张限制；末页判断不受作品文案中的“没有更多了”影响。
- 日期合并优先确切日期；接口失败明确提示并保留已取得结果。停止保留搜索窗口和滚动位置，继续沿原位置读取。
- 修改搜索条件后明确重新搜索，B站官方窗口按钮实际打开官方搜索页。
- 模型完成事件到达后立即收尾，不等待连接关闭；超时与用户取消分别提示。原稿与有效结果保留。
- 图片失败原因及素材身份持久化，重启遗留运行状态恢复为中断；单图调整使用当前可见的方向和参考设置。
- 图文及视频工作台拒绝迟到读取和旧修订覆盖当前稿件；保存核验任务与稿件绑定。视频后台任务有停止入口，轮询失败有明确提示，校对取消后可继续。
- 有字幕时仍优先使用字幕；需要播放及关键帧时可以按需取得原视频，已有视频复用。
