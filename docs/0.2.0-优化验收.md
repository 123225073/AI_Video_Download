## 开源复用决策

继续复用 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 的 YouTube 上传播放列表及 BilibiliSpaceVideo 适配器；作者 ID 必须来自原视频官方元数据或输入的官方主页，不以昵称搜索替代。YouTube优先通过公开oEmbed作者资料识别频道，减少单纯识别作者对音视频格式解析的依赖；B站通过原视频官方元数据获取owner UID。

[XHS-Downloader](https://github.com/JoeanAmier/XHS-Downloader) 将发布作品链接提取放在用户脚本中；本版采用独立官方窗口读取已展示的发布作品，不引入整套服务。参考其使用场景，不复制其未实测下载能力声明。[Douyin_TikTok_Download_API](https://github.com/Evil0ctal/Douyin_TikTok_Download_API) 的作者接口依赖会话/签名并有数据不一致报告；本版不接入外部账号池或把服务部署作为桌面应用的前提，先接入用户可正常打开的官方发布列表，标记实验且待真实账号验收。
