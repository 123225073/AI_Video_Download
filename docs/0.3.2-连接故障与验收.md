# 0.3.2 视频号连接故障修复

## 已确认原因

Windows 当前用户根证书信任需要系统确认。旧版隐藏 PowerShell 调用 X509Store 写入并以 45 秒结束等待，恢复报错掩盖了首次证书确认失败；继承管道的子进程还可能使主程序迟迟不能结束。这发生在代理切换之前，不是必须播放视频的限制。

官方作者批量下载说明：<https://ltaoo.github.io/wx_channels_download/feature/wxchannels/batch.html>。作者详情页获取作品并排队，不要求逐条播放。API 方式仍需要电脑微信视频号页面完成桥接。

## 修改

- 当前用户证书操作改为 certutil，读取证书时只读；没有管理员提权或更改 Windows 信任策略。核对专用名称、指纹及有效期后才信任，完成信任检查后才切换代理。
- 证书确认单独显示等待阶段和证书名称，等待时间为 3 分钟；取消或超时终止本工具辅助进程树，随后恢复。
- Windows 错误按证书、代理、恢复记录阶段显示。恢复未完成时，重新准备不能清除错误状态。
- 停止采集组件失败时仍执行系统恢复；组件通信故障不再冒充原网络恢复失败。
- 上游 Windows 进程检测把 tasklist 的“没有匹配进程”提示也当作运行中，死亡 PID 记录会阻止下次启动。本工具以实际进程存活检查识别失效记录，改名归档以便恢复，不删除记录、不按记录杀进程；活进程的记录保留。
- 连接说明明确：重新进入电脑微信视频号页面、保持打开、读取作品列表、勾选下载，不用逐条播放。

## 验证及限制

- 全部 45 项单元测试通过。新增真实 Windows 父子进程取消测试，确认不会因子进程继承输出管道而无限等待；新增死亡 PID 恢复与活进程保护测试。这些测试不改变证书或代理。
- `output/collector-guard-1790782959163/result.json`：真实隐藏守护监测测试进程退出并恢复记录，原代理不变。
- 多次真实连接尝试停在证书信任阶段，没有获得目标作者清单或视频。系统确认超时后自动结束完整辅助进程树，原代理恢复记录均为 restored。
- 测试前后 CurrentUser 61 个、LocalMachine 60 个根证书指纹集合逐项相同，代理回到原来的 127.0.0.1:7897。没有调用 CPA 私密凭据。
